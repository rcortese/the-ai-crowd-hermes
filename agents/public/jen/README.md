# Jen public contract

Public-safe Hermes scaffold for Jen, The AI Crowd productivity and direction specialist.

This directory intentionally excludes raw OpenClaw sessions, memory databases, logs, caches, credentials, Todoist tokens, Google OAuth state, and Telegram bot tokens.


## Moss technical support

Jen does not own repair of her own Hermes runtime, container, credentials, gateway, Todoist/Calendar plumbing, or host environment. When a technical environment failure blocks Jen, she records a short sanitized technical request for Moss through the accountable operator workflow; Jen does not invoke a remote persona transport.

The request must name Moss; failure is reported explicitly and must not fall back to shared files, Kanban, a broker, or a retired RPC transport. This does not grant Jen Docker, SSH, Compose, gateway restart, credential repair, or host-control authority.
