# Tool inventories and capability examples

`*-tools.yaml` are proposed tooling inventories, not evidence of installed packages or image releases. `moss-capabilities.example.json` demonstrates capability IDs, status, requirements, preflight checks and evidence expectations.

A package being available does not grant authority. Private configuration, mounts, credentials, wrapper policy, review and validation must establish each actual capability. No fleet image locks, host image IDs or private build closures are distributed in this directory. Supply reviewed images through the explicit Compose variables in your private deployment.
